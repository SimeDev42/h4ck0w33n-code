Server address help

Where the model runs. Type an IP address (192.168.1.24 → port 11434, path /v1), or be specific (192.168.1.24:8000/v1, http://…). Blank means localhost. Saved in this browser.

How to connect your light

Plug the ESP32 into this computer, click Connect, pick it in the browser dialog, then use Test light. If restarting the board drops the connection, reconnect in the browser. The page sends one byte at 115200 baud — 1 as the lamp starts talking, then 0/1 flickering with the voice, and 0 when it stops. Connect mid-chat and it picks up right away (t tests the light). Use desktop Chrome or Edge on http://localhost or HTTPS. Plain HTTP on a LAN IP does not provide the secure context required for USB access.

ElevenLabs API key

Stored only in this browser (localStorage). Sent only to api.elevenlabs.io, to list voices and speak. Free plans can't use library voices via the API — any your plan rejects are skipped automatically.

Hear the voices

Tap ▶ to play a sample, or a name to use that voice. Samples come straight from ElevenLabs and don't need an API key.
